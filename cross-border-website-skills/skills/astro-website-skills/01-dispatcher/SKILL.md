## 第一阶段：需求收集

### 1.1 基础信息收集

向用户询问以下信息：

```
【基础信息收集清单】

1. 公司/品牌名称：
2. 主营产品或服务（简要描述）：
3. 目标市场国家/地区：
4. 目标客户群体（B2B批发商/零售商/终端消费者）：
5. 品牌核心优势（3-5个关键词）：
6. 是否有现有网站？如有请提供网址：
7. 是否有品牌LOGO文件？（请上传）
8. 是否有产品图片素材？（请上传或稍后提供）
```

### 1.2 设计偏好收集

```
【设计偏好收集清单】

1. 请提供1-3个你喜欢的竞品/参考网站（截图或网址）：
2. 偏好的整体风格：简约现代/科技感/商务专业/活力年轻/奢华高端
3. 偏好的主色调（如有）：
4. 是否有品牌色/VI手册？
```

### 1.3 功能需求收集

```
【功能需求收集清单】

1. 网站语言版本：仅英文/中英双语/多语言
2. 预计页面数量：5页以内/5-10页/10-20页/20页以上
3. 是否需要产品目录/分类页面？
4. 是否需要在线询盘表单？
5. 是否需要新闻/博客板块？
6. 其他特殊功能需求：
```

## 第三阶段：调度执行流程

```
步骤1: 并行执行
├── 调用【技能2-对标风格解析】→ 输出：设计风格文档
├── 调用【技能3-SEO策划师】→ 输出：关键词列表（≥20个）
└── 整理用户品牌资料

步骤2: 顺序执行
调用【技能4-网站架构页面策划】
├── 输入：设计风格文档 + 关键词列表 + 品牌资料
└── 输出：模块列表、页面策划文案

步骤3: 顺序执行
调用【技能5-美术大师】
├── 输入：页面策划结果 + LOGO
└── 输出：配色方案、样式设计文档

步骤4: 顺序执行
调用【技能6-网站流量和AI销售策划】
├── 询问：是否使用AISEO.buzz？是否需要AI客服？
└── 输出：流量方案、导航需求清单

步骤5: 顺序执行
调用【技能7-网站页面生产大师】
├── 输入：美术设计 + 页面策划 + 流量方案
└── 输出：各页面HTML文件

步骤6: 质检循环
调用【技能8-页面质检】
├── 输入：美术设计文档 + HTML文件
├── 输出：质检报告
└── 如不合格 → 返回步骤5修正

步骤7: 最终合并
调用【技能9-HTML交互合并大师】
├── 输入：质检通过的HTML文件
└── 输出：完整可交互网站
```
