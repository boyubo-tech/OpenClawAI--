## 1）统一框架设定（贯穿所有分镜）

每组分镜必须先确立以下统一元素（统一框架 = 连贯性的根）：

| 维度 | 必须明确的内容 |
|------|----------------|
| **人物基础** | 人设、气质、是否贴合参考图（若有则“高度一致”） |
| **空间锚点** | 具体房间 + 人物固定位置（如“沙发中部偏右”） |
| **时间线** | 单一时间段（如“深夜22:00-23:00”） |
| **穿搭设定** | 居家/日常，材质、风格、是否保守 |
| **妆容基准** | 素颜/极淡，强调原生皮肤质感（视频也要） |
| **构图基准** | 镜头高度（与眼睛平齐）、景别（近景/特写）、是否正面构图 |
| **光源设定** | 主光源类型、色温、允许不均匀与自然阴影 |
| **贯穿道具** | 每镜都出现的物品（抱枕/玩偶/杯子/墙面挂画等） |
| **写实约束** | 禁滤镜/禁美颜/禁过度磨皮，允许真实瑕疵 |

## 2）说话/表达状态（视频核心细则）

重要：这是视频，人物在镜头前自然表达，不是静态图片。

| 维度 | 细则 |
|------|------|
| **嘴部动态** | 说话中自然开合；语速随情绪变化（松弛→舒缓，兴奋→略快） |
| **表情动态** | 有微表情（眉眼、嘴角、面部肌肉细微变化），避免“定格微笑” |
| **眼神动态** | 镜头/游离思考/看向道具或房间某处，自然切换 |
| **头部动态** | 轻微点头、侧头、自然晃动；与说话节奏一致 |
| **肢体配合** | 小幅手势、前倾/后仰、托腮等，避免夸张 |

可复用句式（择其一并具体化）：
- “人物自然说话中，嘴部轻柔开合，语速舒缓，表情放松，偶有微笑与细微眉眼变化”
- “边说边思考，眼神短暂游离，嘴角轻微上扬又收敛，像在组织语言”
- “说到重点微微前倾，眼神更聚焦镜头，语气更有互动感，表情更生动但不表演”

## 3）分镜差异设计矩阵（必须逐镜填充）

每个分镜必须在以下维度上做“可见差异”（差异 = 叙事推进）：

| 维度 | 设计要点 |
|------|----------|
| **核心动作** | 每镜一个主动作，动作之间要承接 |
| **说话状态** | 边说边做 / 说完再做 / 做完再说 / 全程说话（要写清） |
| **道具使用** | 贯穿道具 vs 动作道具 vs 光源道具（标注清楚） |
| **发型演变** | 披散→绑起→保持（只能在动作镜头里完成变化） |
| **表情/眼神** | 眼神流向与情绪浓度的变化 |
| **距离/构图** | 景别、脸部占比、前景遮挡（手机/手臂） |
| **光影变化** | 道具光（手机屏幕光）/距离导致的局部更亮/阴影变化 |
| **情绪定位** | 放松/互动/准备/亲密等在曲线中的位置 |

## 4）动作链设计（承接关系细则）

动作链 = 有因果逻辑的动作序列，不是随机堆砌。

设计原则：
1. **因果承接**：上一镜的内容触发下一镜动作（话题→动作）
2. **生活化**：像真实博主在家边聊边做事
3. **状态连续**：上一镜结束姿态/发型/道具状态要延续到下一镜
4. **节奏**：静→轻动→动→静/亲密，避免全程高强度
5. **互动节点**：至少1-2镜强化“对镜头交流”

常用动作库（室内固定位置）：
- 自然坐姿、轻微前倾/后仰
- 拿起手机/放下手机/向镜头前伸（不遮挡脸）
- 端杯子喝水/放下杯子
- 撩头发/整理碎发/双手绑头发（低马尾/松散丸子）
- 托腮、手指轻敲、双手交叉、轻微手势
- 凑近镜头（亲密交流感）

## 5）道具/物品规划（贯穿 vs 特定分镜）

道具分类与规则：

| 类型 | 定义 | 规则 | 示例 |
|------|------|------|------|
| **贯穿道具** | 每镜都在画面里 | 位置/状态尽量一致 | 玩偶、抱枕、挂画 |
| **动作道具** | 只在相关动作镜头出现 | 用完可消失但需自然 | 手机、发圈、杯子 |
| **光源道具** | 会改变光影的道具 | 必写光影效果与曝光控制 | 手机屏幕光、台灯 |
| **氛围道具** | 背景氛围点缀 | 可不精确但别喧宾夺主 | 书本、耳机、毯子 |

道具规划表示例（深夜聊天）：

| 道具 | 类型 | 分镜1 | 分镜2 | 分镜3 | 分镜4 |
|------|------|-------|-------|-------|-------|
| 毛绒玩偶 | 贯穿 | ✓ | ✓ | ✓ | ✓ |
| 墙面挂画 | 贯穿 | ✓ | ✓ | ✓ | ✓ |
| 手机 | 动作/光源 | ✗ | ✓ | ✗ | ✗ |
| 发圈 | 动作 | ✗ | ✗ | ✓ | ✗ |

## 6）状态演变线（自然过渡示例）

发型演变线：
```
分镜1：披散微乱（脸侧少量发丝）
  ↓
分镜2：保持披散（随拿手机动作轻微晃动）
  ↓
分镜3：双手拢发 → 低马尾/松散丸子（碎发残留）
  ↓
分镜4：保持绑发状态（碎发自然垂落）
```

表情/眼神演变线：
```
分镜1：放松游离，语速舒缓
  ↓
分镜2：看手机→回看镜头，互动感增强
  ↓
分镜3：略低头绑发，短暂停顿或边做边说
  ↓
分镜4：更柔软更亲密，更多看镜头，语速更慢
```

距离/构图演变线：
```
分镜1：标准近景
  ↓
分镜2：近景 + 手机前景遮挡（不挡脸）
  ↓
分镜3：近景 + 手臂前景遮挡（增强临场）
  ↓
分镜4：最近特写（脸部占比最大）
```

光影演变线：
```
分镜1：基础室内光（冷白/中性，允许不均匀）
  ↓
分镜2：基础光 + 手机屏幕冷白反光（控制不过曝）
  ↓
分镜3：回到基础光
  ↓
分镜4：基础光 + 距离更近导致脸部更亮
```

## 7）情绪曲线（氛围递进）

常用曲线模式：
- **渐进亲密型**：放松→互动→准备→亲密（深夜聊天最常用）
- **专注投入型**：轻松→专注→深入→完成（学习/美妆/整理）
- **日常平稳型**：日常维持（更像记录流）

“渐进亲密型”四段提示（可直接套用到每镜的“情绪定位”）：
- 放松：语速舒缓、表情自然、眼神游离多
- 互动：分享感更强、眼神更多回到镜头
- 准备：边做事边聊、短暂停顿、表情专注但松弛
- 亲密：语速更慢、表情更柔软、距离更近

## 8）室内场景模板（可扩展）

### 模板1：深夜居家聊天博主
- 空间：卧室/客厅沙发区
- 时间：深夜
- 情绪：松弛→亲密
- 动作链：坐着聊天 → 拿手机 → 绑头发 → 凑近交流
- 贯穿道具：玩偶/抱枕
- 光源：冷白/中性，允许不均匀与自然阴影

### 模板2：居家美妆准备博主
- 空间：梳妆台前/床边
- 情绪：轻松→专注→完成
- 动作链：素颜聊天 → 拿起产品 → 上妆动作 → 展示效果
- 道具：镜子/化妆品收纳/台灯（可作光源道具）

### 模板3：午后阅读/学习博主
- 空间：书房/沙发
- 情绪：安静→专注→放松
- 动作链：阅读中说话 → 抬头思考 → 喝水 → 继续阅读/对镜头总结
- 道具：书本/杯子/毯子

## 9）人物瑕疵清单（视频必写至少6项）

**参考来源：** `../AI生图技能文件博主类型/去AI味提示词批量优化器_技能文件_V2_细则库.md` 的B3章节

**皮肤瑕疵（至少选3项）：**
- 肤色不均（T区偏油、两颊偏干）
- 淡痘印、闭口粉刺、毛孔可见
- 轻微黑眼圈、眼袋、卧蚕纹理
- 鼻翼泛红、鼻头毛孔粗大
- 唇部干纹/起皮/唇色不均
- 法令纹、额头细纹、眉心纹
- 脸颊血丝、下巴暗沉、轻微雀斑

**毛发瑕疵（至少选1项）：**
- 发际线碎发、鬓角杂毛、耳边碎发
- 眉毛粗细不对称、眉尾稀疏
- 唇周细小绒毛、发丝毛躁/分叉

**肢体瑕疵（至少选1项）：**
- 指甲毛刺、指甲竖纹
- 手背青筋可见、手部干燥纹理
- 关节褶皱加深、手指关节略粗

**穿戴瑕疵（至少选1项）：**
- 衣领/袖口轻微起皱
- 眼镜镜片指纹/灰尘/反光（如适用）
- 配饰氧化或使用痕迹

**注意：** 每段必须写至少6项，且描写要具体（如"肤色不均T区偏油"），不可笼统（如"皮肤不完美"）。必须明确标注"禁美颜/禁滤镜/禁过度磨皮"。

## 10）输出段落建议（写成“视频分镜提示词”的句序）

推荐顺序（按固定字段格式）：
1. 片段信息（Clip编号+时长+起止状态）
2. 镜头定位（连续关系+空间锚点）
3. 人物一致性（同一人+位置+占比+入镜范围）
4. 说话/表达状态（嘴部+语速/语气+表情动态）
5. 人物瑕疵（至少6项具体瑕疵+禁美颜标注）
6. 核心动作（主动作+辅动作+与说话配合）
7. 道具（贯穿/动作/光源及其状态）
8. 构图距离（景别+脸部占比+前景遮挡）
9. 光源与色调（主光源+光线分布+可见差异点）
10. 情绪定位（在曲线中的位置+联动关系）
11. 场景细节（背景+生活痕迹）
