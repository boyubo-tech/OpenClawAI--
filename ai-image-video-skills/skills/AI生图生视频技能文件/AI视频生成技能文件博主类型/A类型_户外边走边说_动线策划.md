# AI视频生成技能文件 - A类型：户外边走边说动线策划（短索引执行入口）

## 文件定位

本文件为 A类型“户外边走边说”的**短索引执行入口**，用于提升规则命中率，避免长文漏读。  
详细动线类型、模板库、动作库、光线策略等请到：`A类型_户外边走边说_动线策划_细则库.md`。

适用场景：人物在户外移动中自然说话/表达，有位移与背景变化（街拍vlog/探店/旅行等）。

**核心特征（视频必守）：边走边说的嘴部/表情/眼神动态 + 位移带来的背景变化。**

## 输入要求（Step 1）

**输入类型识别（必先判断）：**
- **类型A：图片提示词**：用户提供已生成的图片提示词（如"人物形象严格参考上传图片：...走在街道上..."）
- **类型B：图片文件**：用户直接上传图片文件
- **类型C：纯文字需求**：用户只给文字需求，无图片

**启动前必须询问并获取：**

**如果输入是图片提示词（类型A）：**
1. **解析图片提示词**：提取关键信息
   - 人物形象描述（参考图一致性要求、脸型、五官、发型、穿搭等）
   - 人物位置与占比（居中/偏左、占画面高度约X成、入镜范围等）
   - 皮肤瑕疵详细（T区泛油光、鼻翼泛红、毛孔、黑眼圈、唇部干纹、痘印等）
   - 场景环境（街道/商圈/店铺等，背景元素）
   - 当前动作与表情（走在某处、停下、指向等，嘴巴张开说话等）
   - 光线与风格（日间自然光、原生写实主义等）
2. **确认扩展方向**：基于图片中的位置/动作，策划4个连续视频片段的动线（从图片位置出发）
3. **片段数量**：受模型限制，**每次至少输出 4 个视频片段**（Clip_01~Clip_04），每段默认 **12秒**

**如果输入是图片文件（类型B）：**
1. **描述图片内容**：详细描述图片中的人物、场景、动作、表情、瑕疵、位置占比等
2. **提取关键信息**：同类型A的解析步骤
3. **确认扩展方向**：基于图片策划4个连续视频片段

**如果输入是纯文字需求（类型C）：**
1. **博主类型/人设**：街拍/探店/旅行/通勤/散步等
2. **地点类型**：街道/商圈/公园/景区/店铺等
3. **时间段**：清晨/白天/傍晚/夜晚（决定光线逻辑）
4. **情绪基调**：轻松/活力/文艺/治愈等（写出递进方向）
5. **片段数量**：受模型限制，**每次至少输出 4 个视频片段**（Clip_01~Clip_04），每段默认 **12秒**
6. **分镜数量**：建议 3-5 镜/段（户外镜头更短；不稳可收敛到 2-3 镜/段）
7. **动线类型**：直线行进/环绕探索/定点切换/自由漫步
8. **参考图信息**：若有，明确“同一人高度一致”

## 最高优先级硬约束（必须全部满足）

0. **必须按片段输出**：每次输出 **≥4 个12秒片段**（Clip_01~Clip_04），且为**同一人物**；每段写清“本段起始位置/本段结束位置”，保证动线可拼接。
1. **必须写边走边说的表达动态**：每镜都写嘴部动态 + 语速/语气 + 表情动态（至少1句具体描写）。
2. **必须体现位移**：分镜之间背景/位置有可辨识变化；位移逻辑不能“瞬移”。
3. **必须写行进状态**：走动/停下/转身/放慢等与说话节奏匹配。
4. **必须写镜头关系**：跟拍/对拍/侧拍至少明确其一，并保持合理连续。
5. **必须写光线逻辑**：与时间段一致（夜晚=人造光/霓虹；黄金时段=暖侧光等）。
6. **必须写情绪递进**：每镜标注情绪定位，并与语速、表情、镜头距离联动。
7. **必须写人物瑕疵（视频也要）**：每段至少写 **6 项具体瑕疵**（皮肤/毛发/肢体/穿戴），不可笼统；禁美颜/禁滤镜/禁过度磨皮，强调原生皮肤质感。
8. **必须写人物位置与占比**：每段明确人物位置（居中/偏左/偏右）、占比（占画面高度约X成）、入镜范围（胸部以上/半身/全身）。
9. **必须模块协调**：统一框架、动线规划、情绪曲线、瑕疵要求、位置占比、光线逻辑等模块之间必须协调一致，不允许冲突；输出前必须执行模块协调检查，发现冲突自动调整。
10. **字符数强制约束（硬上限500）**：每个片段提示词必须在 **450-500字符**（含标点与空格）；**严格禁止超过500字符（硬上限，无例外）**，禁止少于450字符；超过500字符必须立即删减重写，不达标禁止输出。

## 执行流程（Step 2-6）

**Step 2：信息提取与统一框架建立**

**如果输入是图片提示词或图片：**
1. **解析/描述图片**：提取以下关键信息
   - 人物形象：参考图一致性要求、脸型、五官比例、眉眼结构、发型、穿搭等
   - 人物位置与占比：位置（居中/偏左/偏右）、占比（占画面高度约X成）、入镜范围
   - 皮肤瑕疵：详细列出所有瑕疵（T区泛油光、鼻翼泛红、毛孔、黑眼圈、唇部干纹、痘印等）
   - 毛发瑕疵：发际线碎发、鬓角绒毛、眉毛等
   - 穿戴瑕疵：衣领褶痕、配饰使用痕迹等
   - 肢体瑕疵：指甲毛刺、手部细节等
   - 场景环境：具体地点、背景元素、道具
   - 当前动作：图片中的动作（如"走在街道上，右手指向某处"）
   - 表情状态：图片中的表情（如"嘴巴张开呈说话状态"）
   - 光线风格：光线类型、分布、写实风格要求

2. **建立统一框架**：将图片信息固化为贯穿4段的基础设定
   - 人物形象（严格保持图片中的人物特征）
   - 地点类型（图片中的场景，如"商业街"）
   - 时间段（根据光线推断或询问用户）
   - 穿搭妆容（图片中的服装、配饰等）
   - 瑕疵清单（图片中的所有瑕疵，每段都要写）
   - 镜头关系（根据图片推断：跟拍/对拍/侧拍）
   - 光源基准（图片中的光线类型）

**如果输入是纯文字需求：**
1. **定统一框架**：人物一致性、地点类型、时间段、镜头关系、穿搭妆容基准。

**Step 3-6：视频片段策划（所有输入类型通用）**

3. **先排4段片段骨架**：基于图片中的位置/动作，策划4个连续视频片段
   - Clip_01：以图片位置为起点（如"从图片中的街道位置继续前行"）
   - Clip_02~Clip_04：设计动线承接（如"继续前行→到达店门口→推门进入→店内展示"）
   - 为每段指定：位置点/背景差异点、行进状态、停顿节点、情绪定位
   - 写明“段末位置=下一段段初位置”
4. **定动线与点位**：规划 4 个相邻可达位置点（对应4段），写清“从哪到哪”。
5. **排镜头节奏**：每段以走动为主，可插入1个短停顿（介绍/指向/展示/总结）。
6. **逐段输出**：按 Clip 输出（每段都包含“说话动态 + 行进状态/动作 + 背景差异点 + 镜头角度/景别 + 光线 + 情绪定位 + 起止位置”），**严格保持图片中的人物形象、瑕疵、位置占比等基础设定**。**每段提示词必须在450-500字符（含标点与空格），严格禁止超过500字符（硬上限），超过必须删减重写。**
7. **模块协调检查（自动执行，必须完成）**：
   - **执行时机**：在逐段输出后、最终输出前，必须执行
   - **检查项**（逐项检查，发现冲突立即调整）：
     - **统一框架 vs 动线规划**：动线必须符合统一框架的地点类型、时间段、穿搭设定
     - **位置变化 vs 位移逻辑**：4个位置点必须相邻可达，不能瞬移
     - **情绪曲线 vs 说话动态**：情绪定位必须与语速/语气/表情动态一致（如"兴奋"对应"语速稍快、表情更生动"）
     - **瑕疵要求 vs 人物形象**：瑕疵描写必须与人物形象（如"戴眼镜"）匹配（如必须有"眼镜镜片指纹"）
     - **位置占比 vs 镜头角度**：人物位置/占比必须与镜头角度/景别一致（如"占画面高度约五成"对应"中景"）
     - **光线逻辑 vs 时间段**：光线必须与时间段一致（如"夜晚"不能出现"日间自然光"）
     - **起始/结束位置 vs 动线**：段末位置必须等于下一段段初位置（如"店门口"后不能突然"回到街口"）
   - **自动调整规则**：发现冲突时，优先保持统一框架、瑕疵要求、位置占比等基础设定，调整动线规划、情绪曲线等可变模块
8. **连贯性复核**：位移合理、光线一致、人物一致、情绪递进自然且4段可拼接。
9. **强制质检执行（必须完成）**：
    - **执行时机**：模块协调检查完成后、最终输出前
    - **执行方式**：逐项过检"强制质检清单"（包括模块协调必检项、字符数检查）
    - **字符数检查（硬上限500）**：每段提示词必须统计字符数（含标点与空格），必须在450-500字符之间，**严格禁止超过500字符（硬上限，无任何例外）**
    - **不通过处理**：缺项或不符合任一必检项（包括字符数不达标），**立即停止输出，必须重写**（最多3轮）
    - **重写后流程**：重写后必须重新执行步骤7（模块协调检查）和步骤9（强制质检）

## 强制质检清单（逐项过检，不通过必须重写）

**执行机制（强制）：**
- 输出前必须逐项检查以下所有必检项

- 每轮重写后必须重新执行全部质检项

**片段输出（必检）：**
- [ ] 输出≥4个12秒片段（Clip_01~Clip_04），同一人物一致
- [ ] 每段都写起始位置/结束位置，且段末=下一段段初可衔接
- [ ] 每段都按固定字段格式输出，字段完整无缺项
- [ ] **每段提示词字符数在450-500字符（含标点与空格），禁止少于450，严格禁止超过500（硬上限，无例外，超过必须删减重写）**

**说话/表达动态（必检）：**
- [ ] 每段都写“说话动态”（嘴部动态+语速/语气+表情动态），至少1句具体描写
- [ ] 说话状态与行进状态配合合理（边走边说/停下说）

**人物瑕疵（必检）：**

- [ ] 每段明确人物位置（居中/偏左/偏右）
- [ ] 每段明确人物占比（占画面高度约X成）
- [ ] 每段明确入镜范围（胸部以上/半身/全身）

- [ ] 镜头角度有适当变化，不单一

**光线逻辑（必检）：**
- [ ] 光线逻辑与时间段一致（夜晚=人造光/霓虹；黄金时段=暖侧光等）
- [ ] 光线方向可因位移变化，但时段一致

**情绪递进（必检）：**
- [ ] 情绪递进明确且每段有定位
- [ ] 情绪与语速、表情、镜头距离联动

**一致性（必检）：**
- [ ] 同一人、同一时间线、同一动线无跳变
- [ ] 参考图一致性（若有）贯穿所有片段

**模块协调（必检）：**
- [ ] 统一框架与动线规划不冲突（动线符合地点类型、时间段、穿搭设定）
- [ ] 位置变化与位移逻辑不冲突（4个位置点相邻可达，不能瞬移）
- [ ] 情绪曲线与说话动态不冲突（情绪定位与语速/语气/表情一致）
- [ ] 瑕疵要求与人物形象不冲突（如戴眼镜必须有眼镜瑕疵）
- [ ] 位置占比与镜头角度不冲突（位置/占比与镜头角度/景别一致）
- [ ] 光线逻辑与时间段不冲突（光线必须与时间段一致）
- [ ] 起始/结束位置与动线不冲突（段末位置=下一段段初位置）

**质检不通过处理（强制执行）：**
- 缺项或不符合任一必检项，**立即停止输出，必须重写**
- 最多重写3轮；仍不达标时，向用户报告并请求优先保留项
- 每轮重写后必须重新执行全部质检项（包括模块协调检查）
