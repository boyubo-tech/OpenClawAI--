## 输入要求（Step 1）

**输入类型识别（必先判断）：**
- **类型A：图片提示词**：用户提供已生成的图片提示词（如"人物形象严格参考上传图片：...坐在车内后座..."）
- **类型B：图片文件**：用户直接上传图片文件
- **类型C：纯文字需求**：用户只给文字需求，无图片

**启动前必须询问并获取：**

**如果输入是图片提示词（类型A）：**
1. **解析图片提示词**：提取关键信息
   - 人物形象描述（参考图一致性要求、脸型、五官、发型、眼镜等）
   - 人物位置与占比（居中偏左、占画面高度约六成、胸部以上入镜等）
   - 皮肤瑕疵详细（T区泛油光、鼻翼泛红、毛孔、黑眼圈、唇部干纹、痘印等）
   - 场景环境（车内后座、座椅、道具、窗外等）
   - 当前动作与表情（坐在车内、右手食指向上、嘴巴张开说话等）
   - 光线与风格（日间自然光、原生写实主义等）
2. **确认扩展方向**：基于图片中的动作/场景，策划4个连续视频片段的动作链
3. **片段数量**：受模型限制，**每次至少输出 4 个视频片段**（Clip_01~Clip_04），每段默认 **12秒**

**如果输入是图片文件（类型B）：**
1. **描述图片内容**：详细描述图片中的人物、场景、动作、表情、瑕疵、位置占比等
2. **提取关键信息**：同类型A的解析步骤
3. **确认扩展方向**：基于图片策划4个连续视频片段

**如果输入是纯文字需求（类型C）：**
1. **博主类型/人设**：例如深夜聊天/居家vlog/美妆准备/学习分享
2. **场景设定**：室内空间（卧室/客厅/书房/厨房）+ 时间段（深夜/清晨/午后）
3. **情绪基调**：松弛/温暖/专注/亲密/日常（明确主曲线）
4. **参考图信息**：若有，明确“同一人高度一致”（脸型五官比例等）
5. **片段数量**：受模型限制，**每次至少输出 4 个视频片段**（Clip_01~Clip_04），每段默认 **12秒**
6. **分镜数量**：建议 4-6 镜/段（如模型不稳定可收敛到 3-4 镜/段）

## 最高优先级硬约束（必须全部满足）

0. **必须按片段输出**：每次输出 **≥4 个12秒片段**（Clip_01~Clip_04），且为**同一人物**；每段写清“本段起始状态/本段结束状态”，保证可拼接。
1. **必须写说话/表达动态**：每镜都写嘴部动态 + 语速/语气 + 表情动态（至少1句具体描写）。
2. **必须有动作链承接**：动作之间要因果/时间顺序承接，禁止随机拼接动作。
3. **必须做道具分层**：明确贯穿道具（每镜都有）与动作道具（特定镜头出现），必要时标注光源道具（产生光影变化）。
4. **必须写状态演变**：至少覆盖发型/表情眼神/距离构图三条演变线，禁止突变。
5. **必须写光影/氛围递进**：可用“手机屏幕光/距离更近”制造可见差异，但需符合室内照明逻辑。
6. **必须写情绪曲线**：每镜标注情绪定位（如放松/互动/准备/亲密），并与语速、距离、表情联动。
7. **必须保持同一人同一空间同一时间线**：分镜是连续镜头，空间锚点不允许跳变。
8. **必须写人物瑕疵（视频也要）**：每段至少写 **6 项具体瑕疵**（皮肤/毛发/肢体/穿戴），不可笼统；禁美颜/禁滤镜/禁过度磨皮，强调原生皮肤质感。
9. **必须写人物位置与占比**：每段明确人物位置（居中/偏左/偏右）、占比（占画面高度约X成）、入镜范围（胸部以上/半身/全身）。
10. **必须模块协调**：统一框架、动作链、道具规划、状态演变、情绪曲线、瑕疵要求、位置占比、光源设定等模块之间必须协调一致，不允许冲突；输出前必须执行模块协调检查，发现冲突自动调整。
11. **字符数强制约束（硬上限500）**：每个片段提示词必须在 **450-500字符**（含标点与空格）；**严格禁止超过500字符（硬上限，无例外）**，禁止少于450字符；超过500字符必须立即删减重写，不达标禁止输出。

## 执行流程（Step 2-6）

**Step 2：信息提取与统一框架建立**

**如果输入是图片提示词或图片：**
1. **解析/描述图片**：提取以下关键信息
   - 人物形象：参考图一致性要求、脸型、五官比例、眉眼结构、发型、眼镜/配饰等
   - 人物位置与占比：位置（居中/偏左/偏右）、占比（占画面高度约X成）、入镜范围
   - 皮肤瑕疵：详细列出所有瑕疵（T区泛油光、鼻翼泛红、毛孔、黑眼圈、唇部干纹、痘印等）
   - 毛发瑕疵：发际线碎发、鬓角绒毛、眉毛等
   - 穿戴瑕疵：袖口褶痕、眼镜镜片指纹灰尘等
   - 肢体瑕疵：指甲毛刺、手部细节等
   - 场景环境：具体空间、道具、背景元素
   - 当前动作：图片中的动作（如"坐在车内后座，右手食指向上做强调手势"）
   - 表情状态：图片中的表情（如"嘴巴张开呈说话状态"）
   - 光线风格：光线类型、分布、写实风格要求

2. **建立统一框架**：将图片信息固化为贯穿4段的基础设定
   - 人物形象（严格保持图片中的人物特征）
   - 空间锚点（图片中的场景位置）
   - 时间线（根据光线推断或询问用户）
   - 穿搭妆容（图片中的服装、眼镜等）
   - 瑕疵清单（图片中的所有瑕疵，每段都要写）
   - 镜头基准（根据图片推断：正面/侧面、景别、距离）
   - 光源基准（图片中的光线类型）

**如果输入是纯文字需求：**
1. **定统一框架**：人物（含参考图一致性）、空间锚点、时间线、穿搭妆容、镜头基准、贯穿道具、光源基准。

**Step 3-6：视频片段策划（所有输入类型通用）**

3. **选情绪曲线**：优先“渐进亲密/专注投入/日常平稳”之一，并写出每段情绪定位。
4. **先排4段片段骨架**：基于图片中的动作/场景，策划4个连续视频片段
   - Clip_01：以图片动作为起点（如"保持右手食指向上手势，继续说话"）
   - Clip_02~Clip_04：设计动作链承接（如"放下手势→拿起某物→展示/互动"）
   - 为每段指定：核心动作、关键道具、情绪定位、距离变化
   - 写明“段末状态=下一段段初状态”
5. **段内排动作链**：每段只放 1 个主动作 + 1 个辅动作（避免12秒内容过载），按因果承接排序（动作与说话内容匹配）。
6. **定道具表**：列贯穿道具 1-3 个；动作道具 0-2 个/段；如需光源道具标注光影效果与曝光控制。
7. **写片段提示词**：按 Clip 输出（每段都包含“说话动态 + 动作 + 道具 + 构图距离 + 光源色调 + 情绪定位 + 起止状态”），**严格保持图片中的人物形象、瑕疵、位置占比等基础设定**。**每段提示词必须在450-500字符（含标点与空格），严格禁止超过500字符（硬上限），超过必须删减重写。**
8. **模块协调检查（自动执行，必须完成）**：
   - **执行时机**：在写片段提示词后、输出前，必须执行
   - **检查项**（逐项检查，发现冲突立即调整）：
     - **统一框架 vs 动作链**：动作链必须符合统一框架的空间锚点、时间线、穿搭设定
     - **道具规划 vs 状态演变**：道具出现/消失必须与状态演变（如发型变化）时间点匹配
     - **情绪曲线 vs 说话动态**：情绪定位必须与语速/语气/表情动态一致（如"亲密"对应"语速更慢、表情更柔软"）
     - **瑕疵要求 vs 人物形象**：瑕疵描写必须与人物形象（如"戴眼镜"）匹配（如必须有"眼镜镜片指纹"）
     - **位置占比 vs 构图距离**：人物位置/占比必须与景别/脸部占比一致（如"占画面高度约六成"对应"中景"）
     - **光源设定 vs 光影变化**：光影差异必须符合光源设定（如"冷白灯光"下不能出现"暖黄光晕"）
     - **起始/结束状态 vs 动作链**：段末状态必须等于下一段段初状态（如"发型绑起"后不能突然"披散"）
   - **自动调整规则**：发现冲突时，优先保持统一框架、瑕疵要求、位置占比等基础设定，调整动作链、道具规划、情绪曲线等可变模块
9. **连贯性复核**：同一人物同一空间锚点、演变线自然、道具出现规则一致、4段情绪递进合理且可拼接。
10. **强制质检执行（必须完成）**：
    - **执行时机**：模块协调检查完成后、最终输出前
    - **执行方式**：逐项过检"强制质检清单"（包括模块协调必检项、字符数检查）
    - **字符数检查（硬上限500）**：每段提示词必须统计字符数（含标点与空格），必须在450-500字符之间，**严格禁止超过500字符（硬上限，无任何例外）**
    - **不通过处理**：缺项或不符合任一必检项（包括字符数不达标），**立即停止输出，必须重写**（最多3轮）
    - **重写后流程**：重写后必须重新执行步骤8（模块协调检查）和步骤10（强制质检）

## 输出格式（固定字段格式 - 工业化）

每个**片段（Clip）**必须按以下固定字段顺序输出，不允许缺项或乱序：

```
【Clip_XX · 12秒片段】

[片段信息]
- Clip编号：Clip_01 / Clip_02 / Clip_03 / Clip_04
- 时长：12秒
- 起始状态：[本段开始时的状态，如"发型披散，表情放松"]
- 结束状态：[本段结束时的状态，如"发型绑起，表情更亲密"]

[镜头定位]
- 连续关系：连续镜头/同时间线/同空间锚点
- 空间锚点：[具体房间+固定位置，如"卧室沙发中部偏右"]

[人物一致性]
- 同一人：是（参考图则高度一致：脸型/五官比例/眉眼结构/鼻唇形态/发型走向/神态）
- 参考图要求：严格参考上传图片，杜绝陌生面孔与网红化修饰
- 人物位置：[居中/偏左/偏右/居中偏下]
- 人物占比：[占画面高度约X成，如"约六成"或"约60%"]
- 入镜范围：[胸部以上/半身/全身]

[说话/表达动态 - 必写]
- 嘴部动态：[自然开合/轻柔说话/语速舒缓/语速略快等]
- 语速/语气：[舒缓/中等/略快 + 轻松/分享感/亲密等]
- 表情动态：[放松/带笑意/专注/柔软等，有微表情描写]

[人物瑕疵 - 必写至少6项]
- **如果基于图片提示词/图片**：必须完整保留图片中的所有瑕疵描述（如"T区轻微泛油光、鼻翼两侧泛红、鼻头毛孔粗大可见、眼下轻微黑眼圈与细纹、唇部有干纹且唇色不均、下巴处有淡痘印"）

  - 肢体瑕疵：[至少1项，如"手背青筋可见、关节褶皱、指甲边缘有毛刺"]
  - 穿戴瑕疵：[至少1项，如"衣领轻微起皱、眼镜镜片有轻微指纹与灰尘痕迹"]
- 禁美颜/禁滤镜/禁过度磨皮：明确标注（如基于图片，必须保持"不磨皮不美颜"的要求）

[核心动作 - 必写]
- 主动作：[本段核心动作，如"单手拿起手机展示时间"]
- 辅动作：[可选，如"轻微前倾"]
- 与说话配合：[边说边做/停顿做事/做完再说]

[道具 - 必写]

- 动作道具：[本段出现的道具及状态，如"手机-手持展示，屏幕时间22:43"]

[构图与距离 - 必写]
- 景别：[近景/中景/特写]
- 脸部占比：[中等/偏大/最大]
- 前景遮挡：[无/手机前景/手臂遮挡]
- 镜头角度：[正面构图，与眼睛平齐]

[光源与色调 - 必写]
- 主光源：[冷白/中性/暖黄灯光]
- 光线分布：[略不均匀，允许自然阴影]
- 可见差异点：[如有道具光/距离变化导致的光影差异]

[情绪定位 - 必写]
- 在曲线中的位置：[放松/互动/准备/亲密等]
- 与语速/距离/表情的联动：[如"语速更慢，距离更近，表情更柔软"]

[场景细节]
- **如果基于图片提示词/图片**：必须保持图片中的场景设定（如"坐在车内后座，米色皮质座椅有使用褶皱，右侧放置透明彩球机道具；车顶天窗透出树枝，车窗外可见绿植"）
- **如果纯文字需求**：
  - 背景：[卧室/客厅等，有生活痕迹，非样板间]
  - 生活痕迹：[挂画略歪斜/墙面有使用痕迹/装饰非对称等]
- 全画面清晰度要求：全画面从前景到背景所有元素同等清晰锐利，无任何虚化效果（如基于图片，必须保持此要求）
```

**注意：每个Clip必须完整填写以上所有字段，缺项将导致质检不通过。**

## 强制质检清单（逐项过检，不通过必须重写）

**执行机制（强制）：**
- 输出前必须逐项检查以下所有必检项
- 缺项或不符合任一必检项，**立即停止输出，必须重写**
- 最多重写3轮；仍不达标时，向用户报告并请求优先保留项
- 每轮重写后必须重新执行全部质检项

**片段输出（必检）：**
- [ ] 输出≥4个12秒片段（Clip_01~Clip_04），同一人物一致
- [ ] 每段都写起始状态/结束状态，且段末=下一段段初可衔接
- [ ] 每段都按固定字段格式输出，字段完整无缺项
- [ ] **每段提示词字符数在450-500字符（含标点与空格），禁止少于450，严格禁止超过500（硬上限，无例外，超过必须删减重写）**

**说话/表达动态（必检）：**
- [ ] 每段都写“说话动态”（嘴部动态+语速/语气+表情动态），至少1句具体描写
- [ ] 说话状态与动作配合合理（边说边做/停顿做事）

**人物瑕疵（必检）：**
- [ ] 每段至少写6项具体瑕疵（皮肤至少3项+毛发至少1项+肢体至少1项+穿戴至少1项）
- [ ] 瑕疵描写具体不笼统（如"肤色不均T区偏油"而非"皮肤不完美"）
- [ ] 明确标注"禁美颜/禁滤镜/禁过度磨皮"

**人物位置与占比（必检）：**
- [ ] 每段明确人物位置（居中/偏左/偏右）
- [ ] 每段明确人物占比（占画面高度约X成）

- [ ] 动作之间有承接（因果/时间顺序）
- [ ] 动作与说话内容/节奏配合

**道具规划（必检）：**
- [ ] 贯穿道具在每个片段中位置/状态一致
- [ ] 动作道具仅在相关片段出现
- [ ] 光源道具有光影效果描写与曝光控制

**状态演变（必检）：**
- [ ] 至少3条演变线连续（发型/表情眼神/距离构图）
- [ ] 演变线自然过渡，禁止突变

**光影/氛围（必检）：**
- [ ] 至少1处可见光影差异（道具光/距离变化等）且符合室内照明逻辑

**情绪曲线（必检）：**
- [ ] 情绪曲线明确且每段定位一致
- [ ] 情绪与语速、距离、表情联动

**一致性（必检）：**
- [ ] 同一人、同一空间锚点、同一时间线无跳变
- [ ] 参考图一致性（若有）贯穿所有片段

**模块协调（必检）：**
- [ ] 统一框架与动作链不冲突（动作符合空间锚点、时间线、穿搭设定）
- [ ] 道具规划与状态演变不冲突（道具出现/消失时间点与状态变化匹配）
- [ ] 情绪曲线与说话动态不冲突（情绪定位与语速/语气/表情一致）
- [ ] 瑕疵要求与人物形象不冲突（如戴眼镜必须有眼镜瑕疵）
- [ ] 位置占比与构图距离不冲突（位置/占比与景别/脸部占比一致）
- [ ] 光源设定与光影变化不冲突（光影差异符合光源类型）
- [ ] 起始/结束状态与动作链不冲突（段末状态=下一段段初状态）

**质检不通过处理（强制执行）：**

- 每轮重写后必须重新执行全部质检项（包括模块协调检查）
