## 1）统一框架设定（贯穿所有分镜）

| 维度 | 必须明确的内容 |
|------|----------------|
| **人物基础** | 人设、气质、是否贴合参考图（若有则高度一致） |
| **行进路线** | 从A点到B点的动线（或漫步区域） |
| **时间线** | 单一时段（清晨/下午/傍晚/夜晚） |
| **穿搭设定** | 休闲/时尚/运动/文艺等，配饰是否存在 |
| **镜头关系** | 跟拍/对拍/侧拍，镜头与人物相对位置 |
| **光源设定** | 自然光方向（顺/逆/侧）与时段光特征 |
| **写实约束** | 自然表达、非摆拍、不过度表演 |

## 2）边走边说的表达状态（视频核心细则）

| 维度 | 细则 |
|------|------|
| **嘴部动态** | 边走边说，嘴部自然开合；语速与步态配合 |
| **表情动态** | 随内容与环境自然变化，户外更活泼但不过度夸张 |
| **眼神动态** | 镜头/前方路面/周围环境自然切换 |
| **头部动态** | 走路自然晃动；提到某处时转头看向该方向 |
| **肢体配合** | 手臂自然摆动；重点处可指向/展示/招手 |

可复用句式：
- “人物边走边说，步态轻松自然，嘴部自然开合，语速中等，表情愉悦放松，眼神在镜头与前方间切换”
- “到达关键点位停下转向镜头介绍，语气带期待感，手势指向目标，眼神更聚焦镜头”

## 3）户外动线类型（细则）

| 动线类型 | 特征 | 适用场景 | 镜头建议 |
|----------|------|----------|----------|
| **直线行进** | 沿固定方向前进，背景持续变化 | 街道漫步、商圈穿行 | 正面/侧面跟拍 |
| **环绕探索** | 区域内走动与环顾 | 景点游览、店铺探索 | 多角度切换 |
| **定点切换** | 多个点位间切换 | 探店打卡 | 每点位一个分镜 |
| **自由漫步** | 随意走动 | 日常散步vlog | 自然跟拍 |

## 4）分镜差异设计矩阵（必须逐镜填充）

| 维度 | 设计要点 |
|------|----------|
| **位置/背景** | 每镜背景不同，体现位移 |
| **行进状态** | 走动/停下/转身/加速/放慢 |
| **说话状态** | 边走边说/停下说/指向说/回头说 |
| **动作配合** | 手势、头部动作、展示/指向/推门等 |
| **视线方向** | 看镜头/看前方/看某物/环顾 |
| **表情变化** | 轻松→惊喜→满足等自然变化 |
| **镜头角度** | 正面/侧面/斜后方等 |
| **景别变化** | 近景/中景/全景/特写 |
| **光影变化** | 阴影区→阳光区→逆光等 |
| **情绪递进** | 随内容与空间推进而递进 |

## 5）边走边说动作库（户外）

- 边走边说/边走边看镜头
- 停下脚步/转身面对镜头
- 指向某处/展示某物（菜单/招牌/商品）
- 回头看/侧头看（配合讲述）
- 推门进入/走出某处
- 坐下休息/靠墙站立（作为节奏点）
- 拿出手机/收起手机（可作互动与节奏）
- 挥手/招手（轻量互动）
- 小跑几步/放慢脚步（节奏变化）
- 环顾四周/抬头看（环境互动）

---

## 6）背景变化规划（细则）

原则：
- 每镜都有“可辨识差异”的背景元素（招牌/树荫/路口/橱窗/店门）
- 位移逻辑合理（避免瞬移）
- 背景不过度杂乱抢人物焦点

## 7）户外光线策略（细则）

| 时段 | 光线特征 | 画面效果 | 适用情绪 |
|------|----------|----------|----------|
| 清晨 | 柔和侧光、长影子 | 清新安静 | 治愈文艺 |
| 正午 | 顶光硬阴影 | 明亮对比强 | 活力日常 |
| 下午 | 斜侧光偏暖 | 温暖立体 | 轻松惬意 |
| 黄金时段 | 低角度暖光 | 氛围强 | 浪漫治愈 |
| 夜晚 | 人造光/霓虹 | 城市感 | 潮流活力 |

夜晚补充：
- 面部不宜过暗（可借店铺灯、路灯、橱窗光）
- 控制过曝与炫光，保留城市真实光影

## 8）场景模板库（可扩展）

### 模板1：城市街拍漫步博主
- 地点：商业街/老城区/文艺街区
- 时间：下午或傍晚黄金时段
- 情绪：轻松、时尚、日常
- 动线：直线行进 + 1-2次定点停留

### 模板2：探店打卡博主
- 地点：特色店铺/美食街
- 时间：白天或傍晚
- 情绪：活力、好奇、惊喜
- 动线：店外→推门进入→店内特色区→结尾走出或停留总结

### 模板3：旅行景点博主
- 地点：景区/地标/自然风光
- 情绪：兴奋、治愈、感慨
- 动线：入口→标志点→细节角落→全景收束

### 模板4：日常通勤/散步博主
- 地点：住宅区/公园
- 时间：清晨或傍晚
- 情绪：平静、治愈、日常
- 动线：自由漫步（少切点，多跟拍）

## 9）人物瑕疵清单（视频必写至少6项）

**参考来源：** `../AI生图技能文件博主类型/去AI味提示词批量优化器_技能文件_V2_细则库.md` 的B3章节

**皮肤瑕疵（至少选3项）：**
- 肤色不均（T区偏油、两颊偏干）
- 淡痘印、闭口粉刺、毛孔可见
- 轻微黑眼圈、眼袋、卧蚕纹理
- 鼻翼泛红、鼻头毛孔粗大
- 唇部干纹/起皮/唇色不均
- 法令纹、额头细纹、眉心纹
- 脸颊血丝、下巴暗沉、轻微雀斑

**毛发瑕疵（至少选1项）：**
- 发际线碎发、鬓角杂毛、耳边碎发
- 眉毛粗细不对称、眉尾稀疏
- 唇周细小绒毛、发丝毛躁/分叉

**肢体瑕疵（至少选1项）：**
- 指甲毛刺、指甲竖纹
- 手背青筋可见、手部干燥纹理
- 关节褶皱加深、手指关节略粗

**穿戴瑕疵（至少选1项）：**
- 衣领/袖口轻微起皱
- 眼镜镜片指纹/灰尘/反光（如适用）
- 配饰氧化或使用痕迹

**注意：** 每段必须写至少6项，且描写要具体（如"肤色不均T区偏油"），不可笼统（如"皮肤不完美"）。必须明确标注"禁美颜/禁滤镜/禁过度磨皮"。

## 10）输出段落建议（写成“视频分镜提示词”的句序）

推荐顺序（按固定字段格式）：
1. 片段信息（Clip编号+时长+起止位置）
2. 镜头定位（连续关系+位移说明）
3. 人物一致性（同一人+位置+占比+入镜范围）
4. 说话/表达动态（嘴部+语速/语气+表情动态）
5. 人物瑕疵（至少6项具体瑕疵+禁美颜标注）
6. 行进状态与核心动作（走动/停下/转身+手势）
7. 位置与背景差异点（当前位置+背景元素）
8. 镜头角度与景别（镜头关系+角度+景别+人物占比）
9. 光线（光源方向+色温+阴影情况）
10. 情绪定位（在递进中的位置+联动关系）
